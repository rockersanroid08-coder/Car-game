# NEON RUSH 🏎️⚡

Android Rockers mobile car-dodging game.

## Repo structure

- `index.html` — complete game
- `assets/road.jpg` — 3D road background
- `assets/player-car.png` — blue player car
- `assets/enemy-car.png` — red enemy car

## Run

Open `index.html` directly in a browser, or deploy the folder to Netlify/GitHub Pages/any static host.

No framework, build step, or external dependency is required.
